# Tutoriel ASP.NET Core + Angular

Projet d'apprentissage basé sur le modèle SPA ASP.NET Core + Angular : un contrôleur `Users` avec son gestionnaire côté serveur, et quelques composants Angular (compteur, récupération de données).

## Lancer

```bash
dotnet run   # lance aussi le client Angular via SpaProxy
```

## Pistes d'amélioration

- Migrer vers .NET 10 et une version d'Angular supportée.
- Remplacer l'exemple WeatherForecast par une vraie fonctionnalité et renommer le composant `compooo`.
- Ajouter des tests et une CI.
